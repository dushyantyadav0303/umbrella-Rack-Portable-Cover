## About the Project

**umbrella Rack + Portable Cover** - Umbrella rack for Hanging Umbrella and Portable cover that help to Carry wet umbrella easily.
#### uses scenario
- Portable cover Which looks like a water bottle help to carry Umbrella. And after rain We can keep the wet umbrella inside inside it
- Umbrella Rack Which we Place At the entrance of Our home/Store Where every one can put our umbrella.

### Recommended Print Specifications


> [!Note]
> FDM printing is not good Option for umbrella Rack. <br/>
> Recommended: Use Wool and Screw to make it

| Specification | Default Value / Range |
| :--- | :--- |
| **Printer Nozzle** | 0.4 mm Stainless Steel |
| **Layer Height** | 0.2 mm |
| **First Layer Height** | 0.2 mm |
| **Nozzle Temperature** | Depends on your Filament |
| **Build Plate Temperature** | Depends on your Filament |
| **Sparse Infill Density** | 10% |
| **Max Toolhead Speed** | 500 mm/s |
| **Max Acceleration** | 8000 mm/s² |

 source: `Production`
